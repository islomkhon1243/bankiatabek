# Banki Atabek — каталог продукции

Готовый статический каталог на HTML, CSS и JavaScript с защищённой админ-панелью. Данные и фотографии автоматически сохраняются в GitHub через Netlify Functions.

## Адреса

- Клиентский каталог: `/`
- Админ-панель: `/admin`

На клиентской странице ссылки на админ-панель нет.

## Возможности администратора

- вход по паролю;
- добавление, редактирование и удаление товаров;
- изменение объёмов и цен;
- загрузка фотографии с телефона или компьютера;
- предпросмотр фотографии;
- поддержка JPG, PNG и WebP до 4 МБ;
- автоматическая запись изображения в `assets/images/products/uploads/`;
- автоматическое обновление `data/products.json`;
- запуск нового deploy Netlify после commit в GitHub.

## Развёртывание

1. Создайте GitHub-репозиторий и загрузите содержимое проекта в его корень.
2. В Netlify выберите **Add new site → Import an existing project**.
3. Подключите репозиторий.
4. Build command оставьте пустым, Publish directory укажите `.`.
5. В **Site configuration → Environment variables** добавьте:

- `ADMIN_PASSWORD` — пароль администратора;
- `JWT_SECRET` — длинная случайная строка не короче 32 символов;
- `GITHUB_OWNER` — логин владельца репозитория;
- `GITHUB_REPO` — название репозитория;
- `GITHUB_BRANCH` — `main`;
- `GITHUB_TOKEN` — fine-grained GitHub token с доступом только к этому репозиторию и разрешением **Contents: Read and write**.

6. Запустите новый deploy.
7. Откройте `/admin`, войдите и управляйте каталогом.

## Важно

Загрузка фотографии и сохранение товара создают отдельные commits. Обычно обновление клиентского сайта занимает 1–3 минуты. Удаление товара из каталога не удаляет старую фотографию из истории GitHub автоматически.
