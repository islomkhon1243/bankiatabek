# Banki Atabek — каталог продукции

Статический каталог на HTML, CSS и JavaScript с защищённой админ-панелью. Данные и фотографии автоматически сохраняются в GitHub через Netlify Functions.

## Адреса

- Каталог: `/`
- Админ-панель: `/admin`

## Возможности

- вход администратора по паролю;
- добавление, редактирование и удаление товаров;
- до 6 фотографий у одного продукта;
- загрузка JPG, PNG и WebP с телефона или компьютера;
- удаление сохранённых и выбранных фотографий;
- выбор главной фотографии кнопкой со звездой;
- галерея на клиентском сайте со стрелками, точками и свайпом;
- изменение объёмов, цен, категории, описания и наличия;
- автоматическое сохранение файлов и `data/products.json` в GitHub.

## Настройка Netlify

В переменных окружения Netlify добавьте:

- `ADMIN_PASSWORD` — пароль администратора;
- `JWT_SECRET` — случайная строка не короче 32 символов;
- `GITHUB_OWNER` — владелец репозитория;
- `GITHUB_REPO` — название репозитория;
- `GITHUB_BRANCH` — обычно `main`;
- `GITHUB_TOKEN` — fine-grained token с правом **Contents: Read and write**.

Build command оставьте пустым, Publish directory: `.`.

## Ограничения

- максимум 6 фотографий на товар;
- максимум 4 МБ на одну фотографию;
- каждое новое изображение создаёт отдельный commit;
- удаление ссылки на фотографию из товара не удаляет старый файл из истории GitHub.
